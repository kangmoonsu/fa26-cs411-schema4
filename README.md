## 📌 Project Overview

**Portfolio Rebalancing Strategy Simulator** is a full-stack web application designed to help retail investors evaluate and optimize portfolio rebalancing rules. Unlike static portfolio trackers, our platform simulates and backtests multiple rebalancing strategies (threshold-based, calendar-based, and cash-flow-aware hybrid) under identical historical market conditions using real price data (`yfinance`) and macroeconomic benchmarks (`FRED` risk-free rate).
